### Amazônia Alerta — Data Science & Machine Learning

A data science project focused on predicting high concentrations of fire hotspots in the Brazilian Amazon using historical INPE data from 2022 to 2025.

- Data cleaning, transformation and exploratory data analysis.
- Feature engineering and supervised classification using Scikit-learn.
- Temporal validation and baseline comparison.
- Achieved 66.20% recall on the 2025 test set, compared to a 49.01% baseline.
- PostgreSQL, analytical SQL queries and 17 automated tests.

**Repository:** [Amazônia Alerta](https://github.com/Lucas-PadovanCintra/amazonia-alerta)
